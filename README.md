# qml_hybrid — report

Минимальный ноутбук: MNIST, Fashion MNIST, CIFAR-10; 8 кубитов; PyTorch и PennyLane.

## Установка и запуск

Python 3.11 или новее. Из корня репозитория:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[notebook]"
.venv\Scripts\python -m jupyterlab notebooks/hybrid_qml_est.ipynb
```

Linux/macOS: вместо `.venv\Scripts\python` используйте `.venv/bin/python`.
Выберите ядро созданного окружения. Выполняйте разделы «Импорты», «Настройка обучения»,
«Запуск», затем «Отрисовка результатов». Квантовую схему можно отрисовать до обучения.

Все параметры заданы кодом: архитектура `nn.Sequential`, квантовая цепь, шумы,
shots, градиенты, регуляризация, seed и CPU-процессы. Число процессов выбирайте
по ресурсам компьютера. Параметры по умолчанию перенесены из рабочего ноутбука.
Официальные данные скачиваются в `data/vision`, результаты сохраняются в `runs/`.

## Сохранённые результаты

Обучение для перестроения графиков не требуется. Выполните импорты, затем раздел
«Отрисовка результатов». Положите свои результаты в `runs/noisy_vision/<имя серии>/`.
В `study_name` укажите только имя последней папки, например
`20261021_233017_092277_sv_50k_10k_10k_copy`. Для сравнения задайте папки в
`comparison_studies`. Сами данные и результаты экспериментов в репозиторий не включены.

Бэкенды: `torch_density`, `pennylane_mixed`, `pennylane_statevector`.
Для вектора состояния отключите T1/T2 (`enabled=False`). `shots=None` задаёт
аналитические средние; положительное число — конечные измерения.
Раздел QPU time est сохранён как отдельная оценка времени.
